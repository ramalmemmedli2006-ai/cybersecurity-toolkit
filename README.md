## Project Description

Cybersecurity Toolkit is a Python-based project that combines multiple security tools into one simple command-line application.

This toolkit is designed for:
- Learning cybersecurity fundamentals
- Practicing security analysis
- Demonstrating Python scripting skills
- Building a strong GitHub portfolio project

---

## Included Tools

### 1. Password Strength Checker
Checks whether a password is weak, moderate, or strong based on length and character variety.

### 2. Hash Cracker Demo
Demonstrates dictionary-based cracking of simple hashes for educational purposes.

### 3. Port Scanner
Scans common ports on a target host to identify open services.

### 4. Network Monitor
Monitors active connections and basic network usage information on the local machine.
